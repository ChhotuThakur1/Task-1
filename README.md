# Python Project 1: To-Do List
Industrial Training Project | Batch 2026

## Objective
Build a simple Python program that allows a user to add tasks to a list and view the stored tasks. Focuses on Python Lists, `append()`, loops, `input()`, and output.

## IPO Model
- **Input:** User enters tasks.
- **Process:** Each task is added to a Python list using `append()`.
- **Output:** The program displays all tasks using a loop.

## How to Run
```
python todo_list.py
```

## How It Works
The program starts with an empty list. The user chooses an operation from the menu. When a task is entered, `append()` stores it in the list. The View option uses a `for` loop to display every task. The Exit option ends the program.

## Key Concepts Used
- **List** – Stores multiple tasks in one variable.
- **append()** – Adds a new task to the list.
- **for loop** – Displays tasks one by one.
- **input()** – Takes data from the user.
- **if/elif/else** – Controls program decisions.

## Conclusion
This To-Do List project demonstrates basic data-management concepts. It provides hands-on practice with lists, adding items, loops, and displaying information — a foundation for larger applications and databases.
